# Günay Klima CRM — GitHub Pages demosu

ureten: codex

Yalnız kurgusal verili tarayıcı demosudur. Kayıtlar bu cihazın tarayıcısında tutulur; ekipler arasında ortak değildir. Gerçek müşteri verisi girmeyin. Tarayıcı verileri silinirse demo değişiklikleri silinir; Ayarlar → Veri aktarımı ile yerel yedek alınabilir. Bu depo yalnız yayın dosyalarını içerir; özel CRM sunucusu ve gerçek veriler burada bulunmaz.

Logo ve ürün görselleri Günay Klima / Mitsubishi Electric sahiplerine aittir. React ve Leaflet lisansları dağıtılan dosyalarda korunur.
